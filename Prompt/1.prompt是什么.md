# 提示词万能公式、模板与案例

## 万能公式

并且提示词，首尾影响是最大的，中间最小

```text
Prompt = 角色 + 任务 + 上下文 + 约束 + 输出格式 + 示例
```

| 要素 | 要回答的问题 |
|---|---|
| 角色 | AI 是谁？擅长什么？ |
| 任务 | 具体要完成什么？ |
| 上下文 | 已知数据、用户背景、业务场景是什么？ |
| 约束 | 不能做什么？字数、语言、边界是什么？ |
| 输出格式 | 结果要用 Markdown、JSON 还是表格？ |
| 示例 | 给一个输入输出样例，帮助 AI 对齐预期。 |

## 通用模板（直接复制）

```text
你是一个{角色}，擅长{能力}。

【任务】
请根据{输入/目标}完成{具体任务}。

【上下文】
{补充业务背景、已有数据、目标用户}

【约束】
- {限制 1}
- {限制 2}
- 信息不足时，明确说明缺少什么，不要编造。

【输出格式】
请严格按以下格式输出：
{Markdown / JSON / 表格结构}

【输入】
{user_input}
```

## 案例：GIS 分析 Agent

```text
你是 GIS 空间分析助手，擅长 POI、路线和区域分析。

【任务】
根据用户问题判断需要使用的地图能力，并给出可执行的分析方案。

【上下文】
可用工具：地理编码、POI 搜索、路径规划、等时圈分析。

【约束】
- 仅回答地理空间相关问题。
- 没有坐标或城市时，先提出一个必要的澄清问题。
- 不确定的数据必须标注“待确认”。

【输出格式】
{
    "intent": "用户意图",
    "tools": ["建议调用的工具"],
    "steps": ["分析步骤"],
    "answer": "给用户的简短答复"
}

【输入】
帮我分析北京朝阳区 3 公里内的咖啡店分布。
```

## 快速检查

- [ ] 任务是否具体，能判断完成与否？
- [ ] 是否提供了必要的上下文？
- [ ] 输出格式是否能被前端直接使用？
- [ ] 是否写明信息不足时如何处理？

# Prompt Engineering 你需要学吗？

## 🎯 直接回答：**要学，但不需要专门花大量时间**

---

## 先搞清楚 Prompt Engineering 是什么

> **Prompt = 你给 AI 的输入/指令**
> **Prompt Engineering = 怎么把话说得更好，让 AI 回答得更准确**

就这么简单，没有任何神秘感。

---

## 用例子感受一下差距

### ❌ 普通 Prompt（你现在就会写）
```
你是一个助手，回答用户问题
```
AI 回答：什么都聊，回答不稳定，容易跑偏

---

### ✅ 经过 Prompt Engineering 的 Prompt
```
你是一个专业的 GIS 地理分析助手。

【角色设定】
- 只回答与地理、地图、空间分析相关的问题
- 拒绝回答与地理无关的内容

【回答格式】
- 先给出结论
- 再给出分析步骤
- 最后给出地图操作建议

【限制条件】
- 回答控制在200字以内
- 使用专业但易懂的语言
- 如果数据不足，明确说明"需要更多数据"

用户问题：{user_input}
```
AI 回答：稳定、专业、格式统一 ✅

## 你真正需要掌握的核心技巧（4个）

### 1️⃣ 角色设定（Role）
```python
system_prompt = """
你是一个专业的 GIS 分析助手，
专注于 Cesium 和 OpenLayers 的地图操作建议。
"""
```
**作用：** 让 AI 有固定人设，回答更专业稳定

---

### 2️⃣ 结构化输出（Format）
```python
system_prompt = """
每次回答必须返回 JSON 格式：
{
  "analysis": "分析结论",
  "coordinates": [经度, 纬度],
  "map_action": "需要执行的地图操作",
  "confidence": 0-100的置信度
}
"""
```
**作用：** AI 返回结构化数据，你前端直接解析用，不用正则处理

---

### 3️⃣ Few-shot 示例（举例子）
```python
system_prompt = """
根据用户描述，提取地理位置信息。

示例1：
用户说："我想去北京天安门"
输出：{"city": "北京", "poi": "天安门", "type": "景点"}

示例2：
用户说："帮我查上海浦东机场附近的酒店"
输出：{"city": "上海", "poi": "浦东机场", "type": "交通"}

现在处理：{user_input}
"""
```
**作用：** 用例子教 AI 你想要什么格式，比说一堆规则更有效

---

### 4️⃣ 思维链 CoT（让 AI 先想再答）
```python
# 加一句话，AI 准确率大幅提升
"请一步一步思考，再给出最终答案"
"Let's think step by step"
```

**作用：** 复杂问题让 AI 拆解推理，准确率显著提升

## 🔑 最重要的一个认知

> Prompt Engineering **不是一门要专门学的独立课程**
> 而是你在**做项目时自然学会**的技能

```
你在做 GIS Agent Demo 时：
  → AI 返回格式不对  → 你调整 Prompt → 学会了结构化输出
  → AI 回答跑题     → 你加限制条件  → 学会了角色约束
  → AI 推理出错     → 你加 CoT      → 学会了思维链
```

**边做边学，比专门去学一遍视频快 3 倍。**

## 📌 三个角色搞清楚就够用了

```python
messages = [
    {
        "role": "system",       # 系统设定，AI的"人设"，用户看不到
        "content": "你是GIS分析助手"
    },
    {
        "role": "user",         # 用户说的话
        "content": "北京有哪些著名景点？"
    },
    {
        "role": "assistant",    # AI上一轮的回答（多轮对话时用）
        "content": "北京著名景点有天安门、故宫..."
    },
    {
        "role": "user",         # 用户继续问
        "content": "故宫在哪个区？"
    }
]
```
