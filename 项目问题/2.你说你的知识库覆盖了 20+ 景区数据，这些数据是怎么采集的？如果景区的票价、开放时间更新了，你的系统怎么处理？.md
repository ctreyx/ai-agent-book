> **更新触发机制：**
>
> ```
> 主动触发：
>   → 景区方通知我们更新 → 手动执行更新脚本
>
> 自动触发（进阶）：
>   → 定时任务每天凌晨爬取官网
>   → 对比 MD5 哈希值，内容变了才触发更新
>   → 不变的文档不重新向量化，节省 Embedding 费用
> ```
>
> **回答你说的"直接重新导入"的问题：**
>
> ```
> ❌ 全量重新导入的问题：
>   → 10万条数据重新 Embedding，调 API 花费不少钱
>   → 导入过程可能需要几十分钟，期间知识库状态不一致
>   → 旧向量和新向量可能同时存在，检索结果混乱
>
> ✅ 正确做法：
>   → 按 doc_id 增量更新，只更新变化的部分
>   → 全量重建只在初始化或重大架构调整时才做
> ```
