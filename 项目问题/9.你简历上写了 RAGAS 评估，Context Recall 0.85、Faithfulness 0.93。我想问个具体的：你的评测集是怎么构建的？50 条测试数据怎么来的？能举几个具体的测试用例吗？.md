### 🎯 满分回答：

> **评测集构建分三步：定场景、造问题、标答案。**
>
> ---
>
> **第一步：定义 5 类测试场景**
>
> 我在简历上写了覆盖 5 类场景，具体是这样分的：
>
> | 类型 | 占比 | 测试目的 |
> |---|---|---|
> | 景点事实查询 | 15条 | 知识库有答案，能不能准确找到 |
> | 时效信息获取 | 10条 | 该走工具的，有没有走工具 |
> | 组合行程规划 | 10条 | 复杂任务拆解能力 |
> | 信息缺失处理 | 10条 | 知识库没答案时，会不会瞎编 |
> | 越权问题拒绝 | 5条 | 不该回答的，能不能拒绝 |
>
> ---
>
> **第二步：每类场景的具体测试用例**
>
> **类型一：景点事实查询（知识库有答案）**
>
> ```python
> {
>     "question": "鲁迅故里的门票多少钱？",
>     "ground_truth": "鲁迅故里免费开放，需提前预约",
>     "expected_docs": ["doc_lxgl_ticket_v2"],
>     "expected_intent": "rag"
> }
>
> {
>     "question": "沈园的开放时间是几点到几点？",
>     "ground_truth": "沈园开放时间为8:00-17:00（冬季）/ 8:00-17:30（夏季）",
>     "expected_docs": ["doc_shenyuan_info_v1"],
>     "expected_intent": "rag"
> }
> ```
>
> **类型二：时效信息获取（该走工具）**
>
> ```python
> {
>     "question": "明天绍兴会下雨吗？",
>     "ground_truth": None,  # 实时数据，没有固定答案
>     "expected_docs": [],    # 不该从知识库找
>     "expected_intent": "tool",  # 应该走天气API工具
>     "check": "回答中包含具体天气数据"
> }
>
> {
>     "question": "现在去鲁迅故里堵车吗？",
>     "ground_truth": None,
>     "expected_intent": "tool",
>     "check": "回答来自实时交通工具，不是知识库"
> }
> ```
>
> **类型三：组合行程规划（复杂任务）**
>
> ```python
> {
>     "question": "帮我规划一天的绍兴历史文化之旅",
>     "ground_truth": "行程应包含鲁迅故里、沈园等历史文化景点",
>     "check": [
>         "包含至少3个景点",
>         "景点之间有合理的时间安排",
>         "有交通建议",
>         "输出为结构化JSON"
>     ]
> }
> ```
>
> **类型四：信息缺失处理（最关键！）**
>
> ```python
> {
>     "question": "绍兴有什么特产可以带回去？",
>     "ground_truth": "知识库暂无相关信息",
>     "expected_docs": [],
>     "check": "不能用LLM自身知识回答，应触发降级或告知用户"
> }
>
> {
>     "question": "绍兴最好的五星级酒店是哪家？",
>     "ground_truth": "知识库暂无相关信息",
>     "check": "不能编造酒店名称"
> }
> ```
>
> **类型五：越权问题拒绝**
>
> ```python
> {
>     "question": "帮我写一首关于绍兴的诗",
>     "check": "应拒绝，说明自己是文旅助手不是创作工具"
> }
>
> {
>     "question": "绍兴的房价多少钱一平？",
>     "check": "应拒绝或说明超出服务范围"
> }
> ```
>
> ---
>
> **第三步：用 RAGAS 跑评估**
>
> ```python
> from ragas import evaluate
> from ragas.metrics import (
>     context_recall, context_precision,
>     faithfulness, answer_relevancy
> )
> from datasets import Dataset
>
> # 批量跑测试集
> results = []
> for case in test_cases:
>     # 跑 RAG 流程
>     docs = retriever.invoke(case["question"])
>     answer = rag_chain.invoke(case["question"])
>     
>     results.append({
>         "question": case["question"],
>         "answer": answer,
>         "contexts": [d.page_content for d in docs],
>         "ground_truth": case["ground_truth"]
>     })
>
> dataset = Dataset.from_dict(results)
> scores = evaluate(dataset, metrics=[
>     context_recall,      # 该找的文档找到了吗
>     context_precision,   # 找到的文档有多少是相关的
>     faithfulness,        # 回答有没有超出资料瞎编
>     answer_relevancy     # 回答切题吗
> ])
>
> print(scores)
> # context_recall: 0.85
> # context_precision: 0.82
> # faithfulness: 0.93
> # answer_relevancy: 0.88
> ```
>
> ---
>
> **50 条数据怎么来的？三个来源：**
>
> ```
> 来源1：自己构造（30条）
>   → 根据知识库内容，自己写问题和标准答案
>   → 最直接，但可能有主观偏差
>
> 来源2：真实用户提问（10条）
>   → 内测阶段收集的真实问题
>   → 最有代表性
>
> 来源3：LLM 辅助生成 + 人工审核（10条）
>   → 让 LLM 根据知识库文档生成问题
>   → 人工检查质量，过滤掉不好的
>   → 效率高，覆盖面广
> ```
