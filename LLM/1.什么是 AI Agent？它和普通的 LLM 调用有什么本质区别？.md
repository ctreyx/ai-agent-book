# 🎯 面试场景：什么是 AI Agent？它和普通的 LLM 调用有什么本质区别？

---

## 💬 这样回答（一句话版）

普通 LLM 调用就是"一问一答"，本质上是一个文字接龙机器——你给它一段话，它生成下一段话，仅此而已。它没有记忆、没有工具、不能行动。

AI Agent 的本质区别是它具备了四个核心能力：

```text
Agent = LLM（大脑/思考）
      + Planning（规划/拆解任务）
      + Tools（工具/真正做事）
      + Memory（记忆/上下文管理）
```

最关键的区别是：**LLM 只能"说"，Agent 能"做"。** Agent 有一个 ReAct 循环（思考 → 行动 → 观察 → 再思考），它会根据每一步的结果动态调整下一步行动，而不是一次性把答案全吐出来。

---

## 第一部分：普通 LLM 调用是什么

普通 LLM 调用本质上就是"一问一答"的文字接龙：你给它一段话，它生成下一段话，仅此而已。

它有三个根本性的限制：

```text
❌ 没有工具 — 不能上网、不能查数据库、不能操作任何外部系统
❌ 没有记忆 — 每次对话都是全新的，不记得之前聊了什么
❌ 没有规划 — 不会拆分任务，只能一次性给你一个回答
```

**一句话总结：LLM 只能"说"，不能"做"。**

---

## 第二部分：AI Agent 是什么

AI Agent 是以 LLM 为大脑，具备自主规划、工具调用和记忆能力的智能体。

它的核心公式是：

```text
Agent = LLM（大脑） + Planning（规划） + Tools（工具） + Memory（记忆）
```

| 能力 | 作用 | 类比 |
|---|---|---|
| LLM | 负责思考、理解、决策 | 人的大脑 |
| Planning | 把复杂任务拆成多个步骤 | 人的计划能力 |
| Tools | 调用外部工具执行真实操作 | 人的手和脚 |
| Memory | 记住上下文和中间结果 | 人的记忆力 |

---

## 第三部分：用一个例子说清本质区别

用户说："我想去成都旅游，帮我做个攻略"

| 对比维度 | 普通 LLM | AI Agent |
|---|---|---|
| 回答方式 | 直接生成一段推荐文字 | 先拆分任务，再逐步执行 |
| 信息来源 | 靠训练时的记忆，可能过时 | 调用工具获取实时数据 |
| 能做的事 | 只能聊天 | 查天气、查票价、订酒店 |
| 过程 | 一步完成 | 多步推理、循环决策 |

**普通 LLM 的做法：**

```text
直接生成一大段文字：
"成都是一座美食之都，推荐你去宽窄巷子、武侯祠、锦里..."

问题：
- 信息可能过时（票价变了、景点关了）
- 不知道用户的出发地、时间、预算
- 只是一段"看起来对"的文字，没有任何真实数据支撑
```

**AI Agent 的做法：**

```text
第1步：思考 → 用户要去成都旅游，我需要知道出发时间和预算
       行动 → 追问用户："你打算什么时候去？预算多少？"
       观察 → 用户说"下周五，预算3000"

第2步：思考 → 我需要查机票价格
       行动 → 调用机票查询工具，搜索下周五的机票
       观察 → 查到最便宜的航班是 ¥680

第3步：思考 → 还需要查成都下周的天气
       行动 → 调用天气 API，查询成都下周天气
       观察 → 下周成都有雨，需要调整行程

第4步：思考 → 需要推荐酒店
       行动 → 调用酒店查询工具，按预算筛选
       观察 → 查到3家合适的酒店

第5步：思考 → 信息够了，可以生成攻略了
       行动 → 综合所有信息，生成完整旅游攻略
       输出 → 一份包含真实航班、天气、酒店的定制攻略
```

---

## 第四部分：核心机制 — ReAct 循环

Agent 工作的核心机制叫 ReAct，就是一个不断循环的过程：

```text
思考（Reasoning）→ 行动（Action）→ 观察（Observation）
       ↑                                    │
       └────────────────────────────────────┘
               根据观察结果，再次思考
```

这是 Agent 和 LLM 最本质的区别：

```text
LLM   = 输入 → 输出（一步到位，无论对错）
Agent = 输入 → 思考 → 行动 → 观察 → 再思考 → 再行动 → ... → 最终输出
```

Agent 会根据每一步的执行结果动态调整下一步策略，而不是一次性把答案全吐出来。

---

## 第五部分：总结

如果说 LLM 是一个只会思考的大脑，那 Agent 就是一个有大脑、有手脚、有记忆、会做计划的完整的人。

**LLM 只能告诉你"你可以这样做"，Agent 能帮你"真的去做"。**

## ⚠️ 面试常见追问 & 应对

| 追问 | 回答要点 |
|---|---|
| "Agent 会不会失控？" | 有 Human-in-the-loop 机制，关键步骤需要人确认 |
| "Agent 和 workflow 的区别？" | Workflow 是固定流程，Agent 是动态决策 |
| "多 Agent 协作了解吗？" | 多个 Agent 各自分工，比如一个查资料，一个写报告，一个审核 |
| "你用什么框架搭 Agent？" | LangChain 做基础 Agent，LangGraph 做复杂工作流 |
