# LLM 生成文本时的 Temperature 和 Top-P 这两个参数分别控制什么？它们之间有什么区别和联系？在你的医疗问答场景里，你会怎么设置这两个参数，为什么？

方向是对的，医疗场景低温度低采样的结论也没问题。但回答**偏表面**，面试官会觉得你"知道怎么用，但不知道为什么"。

### 你缺少的技术细节

**Temperature 的本质：**
- LLM 输出时，每个 token 都有一个概率分布（经过 softmax）
- Temperature 是在 softmax **之前**对 logits 做除法：`softmax(logits / T)`
- T 越低 → 分布越**尖锐**（高概率 token 更突出）→ 输出越确定
- T 越高 → 分布越**平坦**（各 token 概率趋于均匀）→ 输出越随机
- T = 0 → 退化为**贪心解码（greedy）**，永远选概率最高的 token

**Top-P（核采样）的本质：**
- 把所有 token 按概率从高到低排序，**累加到概率之和 ≥ P 时截断**，只从这个子集里采样
- Top-P = 0.1 → 只从累计概率前 10% 的 token 里选 → 候选集非常小
- Top-P = 0.9 → 候选集大，允许低概率 token 被选中

**两者的区别与联系：**

| | Temperature | Top-P |
|---|---|---|
| 作用阶段 | 改变概率**分布形状** | **截断**候选集范围 |
| 比喻 | 调音量大小 | 砍掉排名靠后的选手 |
| 极端值 | T=0 → 确定性输出 | P=0.01 → 几乎只选最高概率 |

> ⚠️ **关键点：一般只调一个，另一个设为默认值**。两个同时设很低会过度约束，同时设很高会互相放大随机性。

**医疗场景的设置建议：**
你说的 0.1 方向对，但更专业的说法是：
> "Temperature 设为 **0 或接近 0**，保证输出确定性；Top-P 设为 **1**（不截断），让 Temperature 单独控制。因为医疗场景需要的是**可复现、稳定的输出**，不需要任何创造性。"

另外要注意：**低温度 ≠ 不幻觉**。Temperature 控制的是 token 级别的采样随机性，而幻觉是模型知识层面的问题——即使 T=0，模型"不知道但自信地编"的情况依然会发生。

> 💡 面试建议：基础概念题，面试官考的是**你能不能讲清楚原理**。"温度是创造性"这种比喻可以说，但要紧跟一句技术解释（softmax / logits），才能体现你不是只看过博客。
