# 10.react怎么工作

react就是 thought , acton ,observation

概念： 他让大模型交替生成推理线索和行动，再根据环节返回的结果调整下一步。

整个过程：

模型决策 ——》 工具调用 -》 环境反馈 -》 再次决策

# Thought: 负责记录当前判断，例如还缺什么信息，那个子任务已经完成，下一步应该调用那个工具。 Thought只改变模型后续看到的上下文。

# Action : 包含工具的名称和参数，模型只负责生成Action,真正的搜索，数据库查询，代码执行 由 agent executor 或 harness完成。

# Observation: 工具执行后的真实结果，他可能是一段搜索结果，一个订单状态，一个报错

执行器再把Observation放回上下文，模型再判断下一步做什么。


模型不必提前写死整条操作路线，每次环境反馈都会改变当前状态，后续根据最新状态决定。


生产系统需要补充参数校验，调用预算，循环检测等控制，权限审批和完整轨迹测评。
