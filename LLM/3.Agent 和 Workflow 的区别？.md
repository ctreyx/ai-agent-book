二、Agent 和 Workflow 的区别？
🧠 为什么会问这个？
因为很多人分不清这两个概念，面试官想看你能不能把边界说清楚。

💡 核心区别：一个是固定路线，一个是自主导航
text

Workflow（工作流）= GPS 导航的固定路线
  出发 → 上高速 → 出口下 → 到达
  每一步都是你预先设定好的，不会变

Agent（智能体）= 一个会自己看路况的老司机
  出发 → 发现堵车 → 自己决定绕路 → 遇到施工 → 再调整 → 到达
  每一步都根据当前情况动态决策
对比表
维度	Workflow	Agent
决策方式	预定义的固定流程	LLM 动态决策
执行路径	确定的，A→B→C→D	不确定的，随时可能变
灵活性	低，只能走设计好的路	高，能应对意外情况
可控性	高，结果可预测	低，结果不完全可控
开发难度	简单	复杂
适用场景	流程固定的业务	需要灵活判断的场景
前端类比	固定的表单提交流程	智能路由+动态渲染
用代码看区别
Python

# ============ Workflow 工作流 ============
# 每一步固定，不会变

def workflow(user_input):
    step1 = extract_keywords(user_input)   # 永远先提取关键词
    step2 = search_database(step1)         # 永远第二步搜数据库
    step3 = generate_report(step2)         # 永远第三步生成报告
    return step3

# 永远是 1 → 2 → 3，不管输入是什么


# ============ Agent 智能体 ============
# 每一步由 LLM 动态决定

def agent(user_input):
    while not finished:
        # LLM 自己决定下一步做什么
        thought = llm.think(user_input + history)

        if thought == "需要查天气":
            result = weather_tool(city)
        elif thought == "需要查地图":
            result = map_tool(location)
        elif thought == "需要计算":
            result = calculator(expression)
        elif thought == "信息够了":
            return llm.generate_final_answer()

        history.append(result)   # 记住中间结果，下一轮继续思考
实际项目中怎么选？
text

你的 GIS 项目举例：

Workflow 适合的场景：
  "每天定时生成城市交通热力图报告"
  流程永远是：采集数据 → 清洗 → 分析 → 生成图表 → 发邮件
  不需要灵活判断，固定流程

Agent 适合的场景：
  "用户用自然语言做地图分析"
  用户可能说各种各样的话，Agent 需要理解意图，
  自己判断用哪个工具，执行多少步，每次都不一样
🔥 2026年的真相：大多数生产级项目是混合架构
text

实际项目 = Workflow + Agent 混合

大流程用 Workflow 固定下来（稳定可控）
关键节点用 Agent 做灵活决策（智能灵活）

举例：
  ┌─ Workflow 固定流程 ─────────────────────────┐
  │                                              │
  │  接收用户输入 → [Agent: 意图识别] → 路由分发  │
  │                      │                       │
  │              ┌───────┼───────┐               │
  │              ↓       ↓       ↓               │
  │           查天气   查地图   写报告             │
  │           (工具)   (工具)  [Agent]            │
  │              │       │       │               │
  │              └───────┼───────┘               │
  │                      ↓                       │
  │              固定格式化输出                    │
  └──────────────────────────────────────────────┘
面试完整回答
"Workflow 和 Agent 的核心区别在于决策方式。Workflow 是预定义的固定流程，每一步都是确定的，比如 A→B→C→D，适合流程稳定、不需要灵活判断的场景。Agent 是由 LLM 动态决策的，它会根据当前的情况自主选择下一步做什么，适合需要灵活应对各种用户输入的场景。

在实际生产中，我们通常是混合使用的：大流程用 Workflow 固定下来保证稳定可控，关键节点用 Agent 做灵活决策。比如我做的 GIS 项目里，整体流程是 Workflow 编排的，但意图识别和分析这些节点是 Agent 来做动态判断的。LangGraph 正好支持这种混合架构。"
