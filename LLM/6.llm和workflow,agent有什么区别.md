
llm : 一问一答，输出结果

workflow:用预设步骤编排模型和工具，路径由预设者开发决定

ai agent: 围绕目标动态设计规划，调用工具，观察反馈并继续行动


# 本质区别，就是问下一步谁说了算，决策权再谁手里，这就是分界线

llm: 生成一段结果后就结束

workflow: 由开发者决定顺序，分支，重试规则

ai agent: 由ai 根据目标和观察结果再决定下一步

# 适合场景

llm: 适合翻译，问答

workflow:内容审核，导出报表，工单路由，变量清晰逻辑明确，数据校验规则固定，上agent会自己乱加步骤和校验，耗时耗成本，而且结果每次还不一样

agent:适合写代码，研究，排查问题


# agent的问题

1. 可靠性：错误级联，结果波动
2. 成本与延迟：多次调用的成本
3. 安全与权限：工具调用可能带来权限问题
4. 结果和评估：不能只看答案，要看轨迹

自主性越高，系统治理越不能缺
