# 你的 CrossEncoder Reranker 每次请求都要重新加载模型，会有什么性能问题？Python 里怎么实现"只初始化一次"的单例模式？

## 你的想法非常好！这就是工程化思维 🎯

```
面试官："你怎么避免模型每次重复加载？"

✅ 你的回答：
"我设计了一个全局 ModelManager 单例类，
把 Reranker、Embedding 模型、LLM、向量库
这些重型对象统一在这里初始化和管理。

FastAPI 启动时通过 Lifespan 调用 manager.init()
加载一次后全局共享，其他模块直接 import 使用。

好处是：
第一，模型集中管理，不散落在各个文件里
第二，可以加状态监控，知道哪些模型已加载
第三，想切换模型只改 ModelManager 一个地方
第四，测试时可以 mock 替换，不加载真实模型"
```

## 先回答 lru_cache 靠不靠谱

```
靠谱，但有局限性：

✅ 优点：
  → 简单，一个装饰器搞定
  → 天然懒加载
  → 线程安全

⚠️ 局限：
  → 只能缓存"可哈希参数"的函数
  → 没有统一管理，模型散落各处
  → 不好统一监控（哪些模型加载了，占了多少内存）
  → 测试时不好 mock 替换
```

**你说的"全局管理库"比 lru_cache 更专业，这是大厂的标准做法。**

## 帮你把这个想法写出来

```python
# model_manager.py（你说的全局管理库）

from sentence_transformers import CrossEncoder
from langchain_community.embeddings import DashScopeEmbeddings
from langchain_openai import ChatOpenAI
from langchain_pinecone import PineconeVectorStore
import os

class ModelManager:
    """
    全局模型管理器
    所有 AI 相关的重型对象在这里统一初始化和管理
    """
    
    _instance = None      # 单例
    _initialized = False  # 是否已初始化
    
    def __new__(cls):
        # 保证全局只有一个 ModelManager
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
    
    def init(self):
        """启动时调用一次，初始化所有模型"""
        if self._initialized:
            return  # 已经初始化过了，不重复执行
        
        print("🚀 初始化模型...")
        
        # 注册 reranker
        self.reranker = CrossEncoder(
            "BAAI/bge-reranker-v2-m3"  # 中文模型
        )
        print("✅ Reranker 加载完成")
        
        # 注册 embedding 模型
        self.embeddings = DashScopeEmbeddings(
            model="text-embedding-v3",
            dashscope_api_key=os.getenv("DASHSCOPE_API_KEY")
        )
        print("✅ Embeddings 加载完成")
        
        # 注册 LLM
        self.llm = ChatOpenAI(
            model="deepseek-chat",
            api_key=os.getenv("DEEPSEEK_API_KEY"),
            base_url="https://api.deepseek.com",
            temperature=0.7
        )
        print("✅ LLM 加载完成")
        
        # 注册向量库
        self.vectorstore = PineconeVectorStore.from_existing_index(
            index_name="demo",
            embedding=self.embeddings,
            pinecone_api_key=os.getenv("PINECONE_API_KEY")
        )
        print("✅ VectorStore 加载完成")
        
        self._initialized = True
        print("🎉 所有模型初始化完成！")

# 全局单例（模块级变量）
manager = ModelManager()
```

## 在 FastAPI 里接入（Lifespan）

```python
# main.py
from contextlib import asynccontextmanager
from fastapi import FastAPI
from model_manager import manager

@asynccontextmanager
async def lifespan(app: FastAPI):
    # 服务启动时：初始化所有模型
    manager.init()
    
    yield  # 服务运行中...
    
    # 服务关闭时：清理资源
    print("释放模型资源...")

app = FastAPI(lifespan=lifespan)
```

# rag.py
from model_manager import manager

def rerank_documents(query: str, docs: list, top_n: int = 3):
    # 直接用 manager.reranker，不需要初始化
    pairs = [(query, doc.page_content) for doc in docs]
    scores = manager.reranker.predict(pairs)
    ranked = sorted(zip(scores, docs), key=lambda x: x[0], reverse=True)
    return ranked[:top_n]

def search_knowledge(query: str):
    # 直接用 manager.vectorstore
    return manager.vectorstore.similarity_search(query, k=10)

## 你的方案额外的好处

### 好处一：统一监控

```python
def get_status(self) -> dict:
    """查看所有模型状态"""
    return {
        "reranker": "loaded" if hasattr(self, "reranker") else "not loaded",
        "embeddings": "loaded" if hasattr(self, "embeddings") else "not loaded",
        "llm": "loaded" if hasattr(self, "llm") else "not loaded",
        "vectorstore": "loaded" if hasattr(self, "vectorstore") else "not loaded",
    }

# 健康检查接口
@app.get("/health")
def health_check():
    return manager.get_status()
```

### 好处二：灵活切换模型

```python
# 想换模型？改一个地方就行
class ModelManager:
    def init(self):
        # 开发环境用小模型
        if os.getenv("ENV") == "development":
            self.reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")
        else:
            # 生产环境用中文大模型
            self.reranker = CrossEncoder("BAAI/bge-reranker-v2-m3")
```
