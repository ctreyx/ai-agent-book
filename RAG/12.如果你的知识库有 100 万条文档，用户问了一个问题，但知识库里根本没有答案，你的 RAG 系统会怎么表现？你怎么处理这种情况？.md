### 🎯 满分回答：

> **知识库里没有答案时，RAG 系统会出现两种危险行为：**
>
> ```
> 危险行为1：检索到了不相关的文档，LLM 硬着头皮用这些文档编答案
>   → 用户看到的是一个"看似专业但完全错误"的回答
>   → 这比不回答更危险！尤其在医疗场景
>
> 危险行为2：检索到的文档相关性很低，但 LLM 忽略文档直接用自己的知识回答
>   → 绕过了 RAG 的约束，等于没有 RAG
>   → 可能产生幻觉
> ```
>
> **解决方案：三层防线**
>
> ---
>
> **第一层防线：检索阈值过滤**
>
> ```python
> # 检索后，检查相关性分数
> docs_with_scores = vectorstore.similarity_search_with_score(
>     query=question,
>     k=10
> )
> 
> # 设置阈值，过滤掉不相关的文档
> SIMILARITY_THRESHOLD = 0.75  # 余弦相似度阈值
> 
> relevant_docs = [
>     (doc, score) for doc, score in docs_with_scores
>     if score >= SIMILARITY_THRESHOLD
> ]
> 
> if len(relevant_docs) == 0:
>     # 没有任何文档达标 → 进入降级策略
>     return "抱歉，当前知识库中暂无相关信息，建议咨询专业医生。"
> ```
>
> **阈值怎么定？**
>
> | 方法 | 说明 |
> |---|---|
> | **经验值** | 余弦相似度 0.7-0.8 是常用起点 |
> | **标注数据** | 标注100条好结果和坏结果，找分界线 |
> | **Reranker 分数** | CrossEncoder 分数 < 0.5 基本不相关 |
>
> ---
>
> **第二层防线：Prompt 层面约束 LLM**
>
> ```python
> rag_prompt = """你是医疗知识助手。请根据以下参考资料回答问题。
> 
> 【重要规则】
> 1. 只根据参考资料回答，绝对不要使用你自己的知识
> 2. 如果参考资料中没有相关信息，你必须回答：
>    "根据现有资料无法回答该问题，建议咨询专业医生"
> 3. 不要猜测，不要编造
> 
> 【参考资料】
> {context}
> 
> 【用户问题】
> {question}
> """
> ```
>
> **很多人只做了检索阈值过滤，但忘了在 Prompt 里也要约束。双重保险。**
>
> ---
>
> **第三层防线：降级策略链**
>
> ```
> 用户提问
>     ↓
> 知识库检索 → 有相关结果（分数达标）？
>     │                    │
>     │ Yes               │ No
>     ↓                    ↓
>  正常 RAG 回答      降级策略1：Web Search
>                         ↓
>                    搜到相关信息？
>                     │         │
>                     │ Yes     │ No
>                     ↓         ↓
>                用搜索结果     降级策略2：
>                回答          诚实告知用户
>                             "暂无相关信息"
> ```
>
> ```python
> async def smart_rag_query(question: str):
>     # 1. 先查知识库
>     docs = retriever.invoke(question)
>     top_docs = rerank_documents(question, docs, top_n=3)
>     
>     # 2. 检查最高分是否达标
>     best_score = float(top_docs[0][0]) if top_docs else 0
>     
>     if best_score >= 0.5:
>         # 知识库有答案 → 正常 RAG
>         return generate_answer(question, top_docs)
>     
>     elif best_score >= 0.3:
>         # 可能相关但不确定 → 回答 + 提示不确定
>         answer = generate_answer(question, top_docs)
>         return f"{answer}\n\n⚠️ 提示：以上信息置信度较低，建议进一步确认。"
>     
>     else:
>         # 完全不相关 → 降级到 Web Search 或诚实告知
>         try:
>             web_results = web_search(question)
>             return generate_from_web(question, web_results)
>         except:
>             return "抱歉，当前知识库中暂无相关信息，建议咨询专业医生。"
> ```
>
> ---
>
> **总结：三层防线缺一不可**
>
> ```
> 第一层：检索阈值 — 过滤不相关文档
> 第二层：Prompt 约束 — 让 LLM 不要硬编答案
> 第三层：降级策略 — Web Search 兜底 或 诚实告知
> ```
