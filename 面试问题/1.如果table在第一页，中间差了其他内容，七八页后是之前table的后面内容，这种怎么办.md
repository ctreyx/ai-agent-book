# 如果table在第一页，中间差了其他内容，七八页后是之前table的后面内容，这种怎么办

## 表格被中间大量内容隔断，怎么拼回来？

---

### 问题场景

```
第 1 页：  表格前半部分（景区1-5）
第 2 页：  大段文字介绍
第 3 页：  图片
第 4-6页： 其他内容
第 7 页：  另一张不相关的表格
第 8 页：  第1页那张表格的后半部分（景区6-20）
```

**不是相邻页，中间隔了七八页，不能只看"上一页"来判断。**

---

### 解决方案：给每个表格片段算指纹，全局匹配

```python
def merge_scattered_tables(all_tables):
    """
    all_tables: [(page_num, table_data), ...]
    每页提取出的所有表格，带页码
    """
    # ===== 第一步：给每个表格片段提取特征指纹 =====
    # 指纹 = 列数 + 表头内容
    
    groups = {}  # key: 指纹, value: [片段1, 片段2, ...]
    
    for page_num, table in all_tables:
        # 判断第一行是不是表头
        first_row = table[0]
        col_count = len(first_row)
        
        # 指纹：列数 + 表头文本
        # 比如 "4_景区_门票_时间_地址"
        fingerprint = f"{col_count}_{'_'.join(first_row)}"
        
        # 如果第一行不像表头（全是数字），就用列数作为指纹
        if all(cell.replace('.','').isdigit() for cell in first_row if cell):
            # 没有表头，去已有的 group 里找列数匹配的
            for key in groups:
                if key.startswith(f"{col_count}_"):
                    fingerprint = key
                    break
        
        if fingerprint not in groups:
            groups[fingerprint] = []
        
        groups[fingerprint].append({
            "page": page_num,
            "data": table
        })
    
    # ===== 第二步：同指纹的片段按页码排序，拼接 =====
    merged_tables = []
    
    for fingerprint, fragments in groups.items():
        # 按页码排序
        fragments.sort(key=lambda x: x["page"])
        
        # 第一个片段保留完整（含表头）
        merged = fragments[0]["data"].copy()
        header = merged[0]
        
        # 后续片段去掉重复表头，拼数据行
        for frag in fragments[1:]:
            if frag["data"][0] == header:
                merged.extend(frag["data"][1:])  # 跳过重复表头
            else:
                merged.extend(frag["data"])       # 没表头直接拼
        
        merged_tables.append(merged)
    
    return merged_tables
```

**核心逻辑：不看页码远近，只看列数和表头是否一致。一致就是同一张表，拼起来。**

---

### 面试回答（20 秒版）

> "不能只看相邻页。我的做法是给每个表格片段算一个**指纹**——用列数加表头内容。然后全局扫描整个文档所有的表格片段，指纹相同的就是同一张表被打散了，按页码顺序拼回去，重复表头去掉。不管中间隔了多少页，只要列结构一致就能匹配上。"
